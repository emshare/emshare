# 盘口异动接口

> 渠道：[eastmoney](../eastmoney.md) ｜ 源码：`src/em/channels/eastmoney/ashare_stocks/stock_changes/stock_changes_em.py`

## 接口名称

`stock_changes_em` / `df_stock_changes_em`：盘口异动（大笔买入 / 大笔卖出、火箭发射、封涨停板等 22 种）

## 目标地址

- <https://quote.eastmoney.com/changes/>

## 描述

按异动类型一次取回最近一个交易日的全部记录，按时间倒序。走 `push2ex` 主机的 `getAllStockChanges`（与涨跌停股池同主机、同 `ut`），响应同为 `rc=0` 的 JSON，传输层协议校验无需特判。一个接口用 `change_type` 覆盖 akshare `stock_changes_em` 的 22 个 `symbol`，类型与顺序同东财页面：

## 数据范围（实测）

- **只有最近一个交易日。** 上游不认日期参数（传 `date=20261105` / `20261030` 返回的都是同一份数据），响应里也没有日期字段，`time` 只有 `HH:MM:SS`。2026-11-08（周日）实测返回的是 11-06 的数据；要知道数据属于哪天，可看 `board_changes_em` 返回的 `date`。
- **当天没有记录的类型**：上游 `rc=0`、`data` 为 `null`，映射为 `total=0` 的空页。
- **一次取全量**：上游不限 `pagesize`（50000 也一次返回全部），本接口取 50000，一次请求拿到 `total` 条。akshare 用 5000，单类型超过 5000 条时只拿到前 5000 条。
- 响应体与全量 K 线同量级（快速反弹 2576 条约 243KB），读预算与 K 线相同。

## 字段处理

- **相关信息各位的含义按类型不同**（见上表）。东财页面只显示第 1 位：成交类显示成“手”（股数除以 100），涨跌类显示成百分比，价格类显示成“元”。本接口按类型取出价格与涨跌幅，含义靠算术与东财个股详情页的独立字段 `p` / `u` 对照核实：
  - `price`：异动时的价格。大笔买入 / 卖出是成交价，`股数 × 价格 = 金额` 精确成立（如 29500 × 55.59 = 1639905）。
  - `change_pct`：上游是比例（`0.100198`），转成 %（`10.0198`），保留 4 位即原值精度。涨跌类的第 1 位多数与第 3 位相同，60 日大幅上涨 / 下跌偶有不同（如 `0.037618,6.60000,0.034483`），本接口取与价格配对的第 3 位。
  - `volume` / `amount`：只有成交类 4 种有，其余为 `None`。大笔买入 / 卖出是成交量 / 成交额；有大买盘 / 有大卖盘是多档挂单合计，金额不等于股数 × 价格（如有大买盘均价落在价格下方）。单位是**股**，不是手（大笔卖出常有 108058 这类非整手数）。
- **实测偏差**：大笔买入 / 卖出的 `change_pct` 个别记录对应成交前一笔的价格，与 `price` 差一两个价位（如 002088 成交价 11.09，涨跌幅 9.13% 对应 11.00）。上游原值，未做修正。
- 未核实含义的位置不映射：封涨停 / 封跌停板的第 2 位（疑似封单量）、60 日新高 / 新低的第 1 位（新高 / 新低价，与价格差一个价位内）、涨跌类的第 1 位。需要时从 `info` 取，`info` 是上游原始字符串。
- 时间 `92403` → `09:24:03`。
- `market`：上游 `m` 为 1 是 `sh`，为 0 是 `sz`；北交所也挂在 0 下，按代码段（`4` / `8` / `92` 开头）识别为 `bj`。可连同 `code` 直接传给 `stock_kline_em`。
- 名称为上游原样，如 `英 力 特` 中间带空格。

## 与 akshare 的差异

- akshare 输出的“板块”列其实是异动类型名，本接口叫“异动类型”。
- akshare 丢弃了市场前缀 `m`，本接口保留为 `market`。
- akshare 只给原始“相关信息”字符串，本接口另外拆出价格、涨跌幅、数量、金额，原始字符串仍保留。

## 输入参数 `StockChangesQuery`

| 名称 | 类型 | 必填 | 默认值 | 描述 |
| --- | --- | --- | --- | --- |
| `change_type` | `str` | 否 | `"big_buy"` | 异动类型，见上表，未知回退 `big_buy` |

## 输出参数 `StockChangesPage`

| 名称 | 类型 | 单位 | 描述 |
| --- | --- | --- | --- |
| `change_type` | `str` | — | 规范化后的异动类型 |
| `total` | `int` | — | 该类异动的记录数（上游 `tc`） |
| `items` | `tuple[StockChange, ...]` | — | 全部记录，按时间倒序 |

`StockChange` 字段：

| 名称 | 类型 | 单位 | 描述 |
| --- | --- | --- | --- |
| `time` | `str` | — | 异动时间 `HH:MM:SS`（`tm`） |
| `code` | `str` | — | 股票代码（`c`） |
| `name` | `str` | — | 股票简称（`n`） |
| `market` | `str \| None` | — | `sh` / `sz` / `bj` |
| `change_type` | `str \| None` | — | 异动类型（`t`，英文） |
| `price` | `float \| None` | 元 | 异动时的价格（大笔买卖为成交价） |
| `change_pct` | `float \| None` | % | 异动时的涨跌幅 |
| `volume` | `float \| None` | 股 | 成交量 / 挂单量，仅成交类 4 种 |
| `amount` | `float \| None` | 元 | 成交额 / 挂单金额，仅成交类 4 种 |
| `info` | `str \| None` | — | 上游原始相关信息（`i`） |

## DataFrame 列

`df_stock_changes_em` 的列为 时间 / 代码 / 名称 / 市场 / 异动类型 / 价格 / 涨跌幅 / 数量 / 金额 / 相关信息，异动类型显示中文名。数量、金额两列只在大笔买入、大笔卖出、有大买盘、有大卖盘 4 种类型里输出，其余类型没有这两列。

## 接口示例（领域模型 `StockChangesPage`）

```python
from em import stock_changes_em
from em.domain.queries import StockChangesQuery

page = stock_changes_em(StockChangesQuery(change_type="big_buy"))
print(page.change_type, page.total)
for c in page.items[:2]:
    print(c)
```
