## 正式实现

代码主要在 `src/em/core/proxy.py`、`src/em/core/transport.py`，回归位于 `tests/unit/test_proxy_lifetime.py`。

1. **明确传递请求需求**：传输层按当前读取预算、连接配置与外层deadline计算 `min_lifetime`，通过router传给pool.acquire和hold。池保持渠道无关，不依赖业务客户端回调。
2. **领取与复用筛选**：仅向本次请求发放剩余租期大于准入门槛的出口；其他仍活着的出口不拉黑、不记失败，供短预算请求使用。
3. **大响应准入封顶**：准入门槛为 `min(请求预算, 有效租期 / 2)`。有效租期是TTL减安全余量；例如30秒减3秒后，准入最多要求13.5秒，60秒读取提示不会导致永远无法领取。半租期是保守策略选择，不是已证明最优的调参结果。
4. **实际发送前复核**：重新读取代理剩余租期。若因调度等待已不满足准入则不发HTTP、不处罚IP；否则将连接超时限制为不超过剩余租期的一半，再将读取超时限制到剩余部分，确保两项配置之和不超过当前租期。
5. **重复回源抑制**：一次单飞回源后仍无适合出口时，其他请求共享抑制窗口。有存活出口时直到最早租期结束，无存活出口时使用短负缓存。更短预算请求仍走快速路径；后台续期重复收到临期IP也会抑制重复采购。
6. **换批与在途元数据**：最多保留2×proxy_num个尚未到期的可分发出口；在途但已不在分发池的IP继续保留租期元数据，直到归还清理。新批次加入后，旧IP不会单独持续触发后台采购。
7. **统计**：新增 `lifetime_filtered`、`lifetime_hold_rejected`、`lifetime_refill_suppressed`。过滤次数是扫描事件，含同次请求的重复检查，不是唯一IP数。

原实现的同IP软失败重试、最少在飞分发、采购单飞、熔断与失败分级继续使用。本轮新增的是期限约束和重复回源抑制。

## 16 项离线回归

- 临期派发使用较年轻IP，同时允许短预算请求继续用旧IP。
- 读取超时消耗寿命后拒绝hold并更换IP。
- 同一临期IP再次交付只采购一次，后续重试共享抑制窗口。
- 6线程同时需求不满足时合并一次采购，无占用残留。
- 60秒读取提示仍可执行，实际超时合计不超过租期。
- 大提示能换用年轻出口，不反复采购寻找不可能的60秒租期。
- 外层短deadline允许旧出口执行短请求。
- 领取后被调度延迟到过期时，最终派发不发送HTTP、不拉黑IP、不误记HTTP失败。
- 续期保留原在途请求的租期元数据。
- 回源抑制期间，短请求可立即领取旧出口。
- 同IP重复返回不重置未到期租期。
- 2秒短TTL也可运行被租期限制的请求。
- 池不可用时仍禁止隐式直连。
- 后台重复续期在租期结束前被抑制，结束后可正常重新回源。
- 池重叠容量受限，已移出分发池的在途元数据在归还后清理。
- 已知存活IP重复交付跳过重复预筛并清零源连续失败计数。

重复交付实验使用可控假供应商；没有把真实供应商主动强制为重复返回，也没有声称自然发生了该供应商行为。

## 真网关键分支：受控超时实验

候选和正式路径各运行一次，均在首次试验覆盖成功。流程如下：

1. 使用真实供应商获取真实代理，完成100条列表预热。
2. 等该出口本地年龄约20.5秒，剩余约6.5秒。
3. 将本次首个实际HTTP读取超时主动设为0.01秒，真实网络抛出UpstreamReadTimeout。
4. 延迟约0.99秒才将错误交还传输层，模拟错误上报/调度延迟，使剩余租期降到约5.5秒。
5. 下一尝试仍需要约6秒预算，hold被拒绝，换较年轻出口成功返回100条。

这是一项**真实网络上的受控故障实验**，不是自然超时样本。读取超时来自真实网络，没有伪造成功响应或手工抛出假超时；但超短读预算与延迟上报是人为干预，不能用于计算正常故障概率或声称30分钟自然测试已复现同样因果链。

候选、正式均记录 `lifetime_hold_rejected=1`。原IP在第二次尝试中没有被复用，最终在飞占用0、管理器0，无隐式直连。

## 限制与后续观察

- 同步requests的超时是网络阶段预算，不是可强制取消的端到端硬deadline；DNS、持续滴流或已发出的工作仍有既有局限。
- 需求不足时等待冷却到最早租期结束，是抑制采购与短暂不可用之间的取舍。即使供应商下一次可能返回新IP，也不会在冷却期间不断试买。
- 未对新准入策略重新执行30分钟或交易时段稳定性测试；上一轮30分钟资源数据属于前一版本，不能自动作为本轮新策略的长期证明。
- 未声称重复交付发生率、自然hold拒绝概率、最优准入比例或供应商真实到期语义已被确定。后续应监控新增期限统计、每成功页采购量与完整任务P95/P99。
