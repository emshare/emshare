# 账户余额接口核验

已对用户提供的额度查询接口执行只读请求；没有调用代理提取接口，没有使用IP。

接口返回 HTTP 200、纯文本 JSON，包含两个套餐：

- `次数套餐`：`num=8000`、`use=7148`，实时剩余 `852`。
- `流量套餐`：`num=1073741824`、`use=12778309`，不参与 IP 次数额度。

程序只读取“次数套餐”，计算 `num-use`；实时剩余与本地余额取较小值。因此当前本地收费初始余额812不会被接口返回的852放宽。查询失败保留本地保守额度。

实现位置：`src/em/core/usage.py` 的 `refresh_balance()`；配置为 `EM_PROXY_BALANCE_URL` 与 `EM_PROXY_BALANCE_REFRESH_SEC`。查询使用独立 Session、禁止环境代理和重定向；凭证不写日志或SQLite。

离线测试覆盖次数套餐解析、忽略流量套餐、远程余额收紧本地容量和查询失败回退。本次余额查询只读，不追加代理账本。
